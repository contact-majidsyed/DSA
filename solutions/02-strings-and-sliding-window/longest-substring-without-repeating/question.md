# Longest Substring Without Repeating Characters

Difficulty: **MEDIUM**

## Question

Return the maximum length of a substring with no repeated Java char values.

## Input

A string s.

## Output

The length of its longest contiguous substring without repeated characters.

## Example 1

```text
Input: s = "abcabcbb"
Output: 3
```

"abc" is a longest valid substring.

## Example 2

```text
Input: s = "abba"
Output: 2
```

"ab" and "ba" are valid; no length-three substring is valid.
