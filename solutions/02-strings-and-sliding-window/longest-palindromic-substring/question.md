# Longest Palindromic Substring

Difficulty: **MEDIUM**

## Question

Return a longest palindromic substring; any answer is accepted on ties.

## Input

A string s.

## Output

A longest contiguous palindrome; any tied answer is accepted.

## Example 1

```text
Input: s = "babad"
Output: "bab"
```

"aba" is also accepted.

## Example 2

```text
Input: s = "cbbd"
Output: "bb"
```

The longest palindrome has even length.
