# Minimum Window Substring

Difficulty: **HIGH**

## Question

Return the shortest substring of s containing all characters of t, including duplicates; return empty if impossible.

## Input

Strings s and t.

## Output

The shortest substring of s containing every occurrence required by t; empty string if none exists.

## Example 1

```text
Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
```

This window contains A, B, and C.

## Example 2

```text
Input: s = "a", t = "aa"
Output: ""
```

One a cannot satisfy the two required occurrences.
