# Valid Anagram

Difficulty: **LOW**

## Question

Determine whether two lowercase English strings have the same character frequencies.

## Input

Two lowercase English strings s and t.

## Output

true if they contain exactly the same letter counts; otherwise false.

## Example 1

```text
Input: s = "listen", t = "silent"
Output: true
```

Each letter occurs equally often in both strings.

## Example 2

```text
Input: s = "aab", t = "abb"
Output: false
```

The counts of a and b differ.
