# Climbing Stairs

Difficulty: **LOW**

## Question

Count ways to reach step n using steps of size 1 or 2. Define n=0 as one empty sequence. Require 0 <= n <= 91 for a long result.

## Input

A step count n, with 0 <= n <= 91 for this long-returning implementation.

## Output

The number of ordered ways to climb using steps of size 1 or 2.

## Example 1

```text
Input: n = 4
Output: 5
```

The sequences are 1111, 112, 121, 211, and 22.

## Example 2

```text
Input: n = 0
Output: 1
```

There is one empty sequence of moves.
