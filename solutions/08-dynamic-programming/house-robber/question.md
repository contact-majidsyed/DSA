# House Robber

Difficulty: **MEDIUM**

## Question

Return the greatest sum from nonadjacent houses. Values are nonnegative.

## Input

An array nums of nonnegative amounts in adjacent houses.

## Output

The maximum sum obtainable without selecting neighboring houses.

## Example 1

```text
Input: nums = [2,7,9,3,1]
Output: 12
```

Choose values 2, 9, and 1.

## Example 2

```text
Input: nums = [2,1,1,2]
Output: 4
```

Choose the first and last houses.
