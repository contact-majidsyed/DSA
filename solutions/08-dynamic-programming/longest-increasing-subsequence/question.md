# Longest Increasing Subsequence

Difficulty: **MEDIUM**

## Question

Return the length of a strictly increasing subsequence; elements need not be adjacent.

## Input

An integer array nums.

## Output

The length of a strictly increasing subsequence; selected elements need not be adjacent.

## Example 1

```text
Input: nums = [10,9,2,5,3,7,101,18]
Output: 4
```

One valid subsequence is [2,3,7,101].

## Example 2

```text
Input: nums = [2,2,2]
Output: 1
```

Equal values cannot extend a strictly increasing subsequence.
