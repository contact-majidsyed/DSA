# Word Break

Difficulty: **MEDIUM**

## Question

Determine whether s can be split into dictionary words; words can be reused. Dictionary words are nonempty.

## Input

A string s and a dictionary of nonempty words, reusable any number of times.

## Output

true if the whole string can be segmented into dictionary words.

## Example 1

```text
Input: s = "leetcode", wordDict = ["leet","code"]
Output: true
```

Split the string as "leet" + "code".

## Example 2

```text
Input: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
Output: false
```

No sequence of dictionary words covers the entire string.
