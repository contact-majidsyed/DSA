# Binary Tree Level Order Traversal

Difficulty: **MEDIUM**

## Question

Return tree node values grouped by level from left to right.

## Input

A binary-tree root, shown as a level-order array with null for missing children.

## Output

Node values grouped by depth, left to right.

## Example 1

```text
Input: root = [1,2,3,4,5]
Output: [[1],[2,3],[4,5]]
```

Each output list corresponds to one tree level.

## Example 2

```text
Input: root = []
Output: []
```

There are no levels in an empty tree.
