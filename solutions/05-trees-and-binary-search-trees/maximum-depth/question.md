# Maximum Depth of Binary Tree

Difficulty: **LOW**

## Question

Return the number of nodes on the longest root-to-leaf path.

## Input

A binary-tree root. Examples use level-order arrays, with null for missing children.

## Output

The number of nodes on the longest root-to-leaf path.

## Example 1

```text
Input: root = [1,2,3,4]
Output: 3
```

The path 1 -> 2 -> 4 has three nodes.

## Example 2

```text
Input: root = []
Output: 0
```

An empty tree has depth zero.
