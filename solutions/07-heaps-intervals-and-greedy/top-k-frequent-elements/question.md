# Top K Frequent Elements

Difficulty: **MEDIUM**

## Question

Return k values with the greatest frequencies; if frequencies tie, any valid selection and order is accepted. Require 0 <= k <= unique count.

## Input

An integer array nums and k between zero and the number of distinct values.

## Output

k values with greatest frequency, in any order; any valid tied selection is accepted.

## Example 1

```text
Input: nums = [1,1,1,2,2,3], k = 2
Output: [1,2]
```

Their frequencies are 3 and 2, higher than the frequency of 3.

## Example 2

```text
Input: nums = [4,4,4], k = 1
Output: [4]
```

There is only one distinct value.
