# Kth Largest Element in an Array

Difficulty: **MEDIUM**

## Question

Return the kth largest element, counting duplicates separately. Require 1 <= k <= length.

## Input

An integer array nums and k with 1 <= k <= nums.length.

## Output

The kth largest value, counting duplicates separately.

## Example 1

```text
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
```

Descending order begins 6,5.

## Example 2

```text
Input: nums = [2,2,1], k = 2
Output: 2
```

The two occurrences of 2 occupy the first two positions.
