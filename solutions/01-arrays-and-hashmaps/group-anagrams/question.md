# Group Anagrams

Difficulty: **MEDIUM**

## Question

Group words with identical character counts. Input words contain only lowercase English letters.

## Input

An array strs of lowercase English words.

## Output

A list of groups; group order does not matter.

## Example 1

```text
Input: strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["eat","tea","ate"],["tan","nat"],["bat"]]
```

Words within each group have identical letter counts.

## Example 2

```text
Input: strs = ["",""]
Output: [["",""]]
```

Both empty words belong to the same group.
