# Two Sum

Difficulty: **LOW**

## Question

Return the indices of two distinct elements whose sum is target. Assume exactly one answer exists.

## Input

An integer array nums and an integer target.

## Output

Two distinct zero-based indices, in either order.

## Example 1

```text
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
```

nums[0] + nums[1] = 9.

## Example 2

```text
Input: nums = [3,3], target = 6
Output: [0,1]
```

Use the two separate occurrences of 3.
