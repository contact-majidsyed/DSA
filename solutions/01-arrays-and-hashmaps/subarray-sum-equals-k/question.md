# Subarray Sum Equals K

Difficulty: **MEDIUM**

## Question

Count contiguous subarrays whose sum equals k.

## Input

An integer array nums and target sum k.

## Output

The number of nonempty contiguous subarrays summing to k.

## Example 1

```text
Input: nums = [1,2,3], k = 3
Output: 2
```

The matching subarrays are [1,2] and [3].

## Example 2

```text
Input: nums = [0,0,0], k = 0
Output: 6
```

There are three length-one, two length-two, and one length-three matches.
