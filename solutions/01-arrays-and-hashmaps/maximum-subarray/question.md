# Maximum Subarray

Difficulty: **MEDIUM**

## Question

Find the maximum sum of a nonempty contiguous subarray. Input must be nonempty.

## Input

A nonempty integer array nums.

## Output

The largest sum of any nonempty contiguous subarray.

## Example 1

```text
Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
```

The subarray [4,-1,2,1] sums to 6.

## Example 2

```text
Input: nums = [-5,-2,-7]
Output: -2
```

Choose the single element -2; the subarray cannot be empty.
