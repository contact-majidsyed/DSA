# Reverse Linked List

Difficulty: **LOW**

## Question

Reverse a singly linked list in place and return its new head.

## Input

The head of a singly linked list; [] represents null.

## Output

The head of the same nodes with their links reversed.

## Example 1

```text
Input: head = [1,2,3]
Output: [3,2,1]
```

The original last node becomes the head.

## Example 2

```text
Input: head = []
Output: []
```

An empty list remains empty.
