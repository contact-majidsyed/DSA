# 3Sum

Difficulty: **MEDIUM**

## Question

Return unique triplets summing to zero. This solution sorts the input in place.

## Input

An integer array nums.

## Output

All unique value triplets summing to zero; result order does not matter.

## Example 1

```text
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

These are the two unique triplets; indices must be distinct.

## Example 2

```text
Input: nums = [0,0,0,0]
Output: [[0,0,0]]
```

Repeated occurrences do not create duplicate result triplets.
