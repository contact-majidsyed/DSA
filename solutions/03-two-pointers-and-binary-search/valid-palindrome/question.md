# Valid Palindrome

Difficulty: **LOW**

## Question

Ignore non-alphanumeric characters and compare case-insensitively. Assume ASCII input.

## Input

An ASCII string s.

## Output

true if it reads identically in both directions after ignoring punctuation and letter case.

## Example 1

```text
Input: s = "A man, a plan, a canal: Panama"
Output: true
```

The normalized characters form a palindrome.

## Example 2

```text
Input: s = "race a car"
Output: false
```

The normalized string "raceacar" is not a palindrome.
