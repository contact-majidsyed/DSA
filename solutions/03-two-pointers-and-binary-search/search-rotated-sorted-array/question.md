# Search in Rotated Sorted Array

Difficulty: **MEDIUM**

## Question

Find target in a rotated ascending array of distinct integers, returning -1 if absent.

## Input

A rotated ascending array nums of distinct integers and target.

## Output

The zero-based target index, or -1 if absent.

## Example 1

```text
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
```

The value 0 is at index 4.

## Example 2

```text
Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1
```

The target is not in the array.
