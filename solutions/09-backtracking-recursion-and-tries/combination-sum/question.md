# Combination Sum

Difficulty: **MEDIUM**

## Question

Return unique combinations of distinct positive candidates summing to a nonnegative target. Values may be reused. Input is sorted in place.

## Input

Distinct positive candidates and a nonnegative target; candidates can be reused.

## Output

Unique combinations summing to target; combination order does not matter.

## Example 1

```text
Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
```

Reusing 2 is allowed; [3,2,2] is the same combination.

## Example 2

```text
Input: candidates = [2], target = 3
Output: []
```

No combination reaches 3.
