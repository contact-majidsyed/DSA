# Subsets

Difficulty: **MEDIUM**

## Question

Return every subset of distinct integers, including the empty subset.

## Input

An array nums of distinct integers.

## Output

Every subset, including the empty subset; order does not matter.

## Example 1

```text
Input: nums = [1,2]
Output: [[],[1],[2],[1,2]]
```

Each element can be selected or omitted.

## Example 2

```text
Input: nums = []
Output: [[]]
```

The empty set has one subset: itself.
