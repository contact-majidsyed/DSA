# DSA Practice

Practice data structures and algorithms, with solutions and notes.

## Organization

- `solutions/`: Code for practice problems, grouped by topic as needed.
- `notes/`: Concepts, patterns, and complexity analysis.

For each solution, record the problem, approach, time and space complexity, and edge cases.

```sh
cd ~/Projects/DSA

```

The push command works once this repository is connected to GitHub.
