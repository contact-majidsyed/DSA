# How do you prioritize technical debt?: Quick Recall

**Trick:** Translate debt into reliability, delivery, or operating costs, then compare it with competing work.

**Key move:** Propose a bounded fix with a way to check whether it helped.

**Looks like:** recurring manual recovery -> measured effort -> scoped automation -> reduced effort.

**Remember:** Name the cost before proposing cleanup.

The sequence above is a recall aid; use facts from your own experience.
