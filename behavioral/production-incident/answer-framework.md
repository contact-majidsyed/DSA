Difficulty: **HIGH** (estimated preparation effort).

Choose an incident where you can explain both mitigation and prevention.

## Build your own STAR answer

- **Situation:** [Relevant context and stakes, without unnecessary background.]

## Questions to answer

What was the user impact? How did you triage and stabilize service? How did you coordinate communication? What root cause and follow-up actions did you verify?

Use only your real experience. Replace placeholders with facts you can discuss; if an exact metric is unavailable, describe a verifiable qualitative result. Aim for a concise initial answer and retain details for follow-ups.
